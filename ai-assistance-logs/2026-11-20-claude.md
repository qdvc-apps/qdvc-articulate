**Layout**
- `macos/` holds the Swift app, moved with `git mv` so its history follows.
- `gtk4/` is the new edition, in Python like the Case Manager and Empirics ports.
- Shared at the root: `docs/CHECKING.md`, which records how text is checked and is the contract between the two editions, and `sample-texts/`, a sample with deliberate mistakes plus the same text as `.docx`, `.odt` and `.rtf`.

**The GTK edition**
- **Checking:** the Swift checking engine is ported module by module, with the same 22 rules, phrase lists, spelling variants, prompt, output grammar and review pipeline. Spelling uses the GNOME runtime's Enchant dictionaries inside the app itself. There's no grammar checker to match the macOS one.
- **AI engine:** llama.cpp is built from `gtk4/vendor/llama.cpp` if you place a copy there, runs on the CPU only, and is reached through a small C file. Without that copy the app still builds, minus the AI review.
- **Editor:**
  - Documents open in tabs; unsaved changes are kept as drafts and the tabs come back at the next launch, as in GNOME Text Editor.
  - The issue panel (F9) lists every issue with its suggestions, and right-click offers them too.
  - Also included: writing goals in the header bar, find, statistics, Preferences with the macOS edition's five tabs, and import of `.docx`, `.doc`, `.odt` and `.rtf`.
- **Flatpak `qdvc.articulate.gtk4app`:** no network and no file access, so Flatseal should show Network off and no file access listed. The build script refuses a manifest that grants either.
- **Shortcuts that differ from macOS:** a few macOS keys clash with GTK or the desktop, so they changed. Check with AI is Ctrl+Shift+K, and pressing it again stops the check. Next and previous issue are F8 and Shift+F8. Accept is Alt+Return and Ignore is Alt+Delete. `gtk4/docs/DESIGN.md` explains each one.
